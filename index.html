Netlab Tracer

      
بيئة تشبه Packet Tracer على موبايلك: اختر الجهاز من اللوحة تحت، ضعه على مساحة العمل، وصّله بكابل، واضبطه من نافذته أو من الـ CLI.

      
وضع SimulationEvent List وزر Capture / Forward وPlay، واضغط أي حدث لقراءة تفاصيل الحزمة.

      
نافذة لكل جهازPhysical وConfig وCLI. وعلى الـ PC تبويب Desktop فيه IP Configuration وCommand Prompt.

      
أنواع كابلات حقيقيةStraight وCross وFiber. لو استخدمت النوع الغلط الرابط يفضل أحمر.

ورقة الأوامر

    
على الـ PC (Command Prompt)
ipconfig /all
ping 192.168.2.10
tracert 192.168.2.10
arp -a

    
راوتر: ضبط البورت
enable
configure terminal
interface gigabitethernet0/0
 ip address 192.168.1.1 255.255.255.0
 no shutdown
 end

    
راوتر: static route
configure terminal
ip route 10.3.0.0 255.255.255.0 10.23.0.3
end
show ip route

    
سويتش: VLAN
configure terminal
interface fastethernet0/2
 switchport access vlan 10
 end
show vlan brief
show mac address-table

    
PC: DHCP / DNS / Web
ipconfig /renew
nslookup www.netlab.com
ping www.netlab.com
http www.netlab.com

    
Serial / WAN (راوتر)
interface serial0/0/0
 ip address 10.0.0.1 255.255.255.252
 clock rate 64000
 no shutdown

    
Layer 3 Switch (3560/3650)
configure terminal
ip routing
interface vlan 10
 ip address 10.1.1.1 255.255.255.0
 no shutdown

    
DHCP على الراوتر
ip dhcp excluded-address 192.168.1.1 192.168.1.10
ip dhcp pool LAN1
 network 192.168.1.0 255.255.255.0
 default-router 192.168.1.1
 dns-server 8.8.8.8

    
ASA Firewall
enable
configure terminal
interface gigabitethernet1/1
 nameif outside
 security-level 0
 ip address 200.0.0.1 255.255.255.0
 no shutdown
 exit
icmp permit any

    
أوامر الفحص
show ip interface brief
show running-config
show arp
ping <ip>
traceroute <ip>
